## 3. Release Quality Gates (8-Point Checklist)

- [ ] **1. Official Logo:** Uses full source artwork, 3-point crown, crisp high-DPI rendering, and descriptive `alt` text.
- [ ] **2. Mobile Layout:** Validated at 320px, 360px, 390px, and 430px viewports without horizontal scroll overflow.
- [ ] **3. Functional Controls:** Every visible button triggers an active route, modal, or defined action.
- [ ] **4. Link Integrity:** All internal routes, social channels, email, and WhatsApp links return valid destinations.
- [ ] **5. Accessibility:** Meets WCAG contrast standards, visible focus states, and semantic HTML structure.
- [ ] **6. Performance:** Zero broken network requests, smooth font loading, zero layout shifts.
- [ ] **7. Truthfulness:** Zero fabricated balances, fake user counts, or unverified security certifications.
- [ ] **8. Release Build:** Successfully builds without console errors or broken script execution.
