# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion, or pull request.

Report them privately through [GitHub Security Advisories](https://github.com/Egonu-john/Egonux/security/advisories/new). Include the affected page or component, reproduction steps, impact, and any supporting evidence you can safely share.

Do not include passwords, access tokens, identity documents, payment details, or real customer records in the report. EGONUX will acknowledge a reproducible report, assess severity, coordinate remediation, and publish disclosure details only when it is safe to do so.

## Supported release

Security fixes target the current production release on `main`. This Enterprise MVP remains a sandbox and must not process real money or real identity documents.
